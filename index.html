Recomendaciones y gestión del proyecto
⚠ Cuellos de botella críticos
Impresión 3D de piezas grandes (robot de 50 cm) puede tardar 3–5 días → iniciar modelos en sem 4
Integración Arduino Mega ↔ Raspberry Pi 5 es el punto más complejo → investigar protocolo serial desde sem 1
API de IA tiene costo → tener Gemini API (gratuita) lista como alternativa desde el inicio
Batería: robot de ~5 kg necesita batería de alta capacidad bien dimensionada para 2+ horas de autonomía
Sensor de nivel para pastillas: requiere calibración cuidadosa según tipo y tamaño de pastilla
✓ Orden de desarrollo recomendado
1° Dispensador: es lo más mecánico y tardado; todo depende de que funcione primero
2° App y BD: es el hub central del sistema; movilidad e IA dependen de la BD
3° Movilidad: puede desarrollarse en paralelo con el dispensador
4° IA: integrar al final, cuando la BD ya tenga datos reales que consultar
Regla fija: ningún grupo entra a integración total sin pruebas individuales superadas
🔄 Si hay retrasos en algún grupo
Movilidad atrasada → demo en agosto con robot estático; agregar ruedas en fase de mejora final
Dispensador atrasado → reducir a 4 compartimentos para ganar tiempo de fabricación
IA atrasada → reemplazar con botones en pantalla táctil temporalmente
App atrasada → máxima prioridad, no puede retrasarse; es la base de todo el sistema
Las 6 fechas de sesiones grupales son inamovibles: son los únicos puntos de integración real del proyecto
📋 Claves para llegar funcional en agosto
Feature freeze total en semana 16: cero funciones nuevas hasta octubre
Cada grupo necesita un líder que coordine con los otros tres grupos
Documentar la interfaz de cada módulo antes de la sesión grupal de integración (sem 17)
Las semanas 10–14 son críticas: retrasos aquí no se recuperan antes de agosto
Usar Mar + Mié en el colegio exclusivamente para trabajo físico: ensamblaje, soldadura, pruebas mecánicas
Usar las tareas en casa para avanzar código, diseño 3D, investigación y documentación
